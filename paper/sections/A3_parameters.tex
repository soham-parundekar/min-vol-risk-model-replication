\section{Parameters and their provenance}
\label{app:parameters}
Every number the pipeline needs is declared in one configuration file rather
than distributed through the code, so that the whole specification can be read
in one place and a robustness run can vary one input without editing a module.
The table separates values transcribed from a published document from values
that are our own modelling choices, because the two carry very different
authority: the first are facts about the index being replicated and the second
are decisions a reader may reasonably disagree with.
